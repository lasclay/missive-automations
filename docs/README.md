**Ordre de lecture pour préparer la saison :** J7 d'abord (fixer le plafond d'acquisition et
donc le budget total), puis le manuel Meta (le budget total divisé par le plancher des 50 donne
le nombre d'ensembles de publicités qu'on peut réellement alimenter), puis la conférence (monter
le compte et le pipeline créatif dans ces ensembles), puis Suby (écrire l'offre). Fixer le budget
en dernier est l'erreur que J7 démonte ; ouvrir plus d'ensembles que le budget n'en nourrit est
celle que le manuel Meta démonte.

```
J7        →  budget total     = nouveaux clients visés × NCAC cible
Meta      →  nb d'ensembles   = budget hebdo ÷ (CPA cible × 50)
Conférence→  dans chaque ensemble : broad, CBO, 5× CPA par créatif testé
Suby      →  ce que la publicité dit
```
