**Ordre de lecture pour préparer la saison :** J7 d'abord (fixer le plafond d'acquisition et
donc le budget), puis la conférence (monter le compte et le pipeline créatif), puis Suby
(écrire l'offre). Fixer le budget en dernier est l'erreur que J7 démonte.
