# Storyboard vidéo Lasclay

**`STORYBOARD.md`** — le document de travail. 88 concepts, 293 cases.
Pour chaque case : le visuel décrit, le mouvement de caméra, ce qui est dit, le sous-titre
incrusté, le carton, et un prompt d'image IA pour en tirer une planche photoréaliste.

## La règle du mot

Le nom de la plante **ne se dit jamais** : ni en voix off, ni en dialogue, ni en sous-titre
incrusté (le sous-titre transcrit l'audio). Il **peut s'écrire** : carton plein écran,
description, hashtag, nom de produit, commentaire épinglé, bio, site.
