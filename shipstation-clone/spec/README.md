# shipstation-spec — Lasclay

Paquet de spécification pour bâtir une alternative maison à ShipStation.

**Commencer par `00-INDEX.md`.**

18 fichiers, ~5 800 lignes. Conçus pour un chargement à la demande : ne pas tout
lire d'un coup, l'index dit quel fichier charger à quel moment du build.

Statut : la partie « produit ShipStation » est complète. La partie
« configuration réelle du compte Lasclay » (`99-config-lasclay.md`) est un
gabarit à remplir — sans elle, la transition ne sera pas seamless.
