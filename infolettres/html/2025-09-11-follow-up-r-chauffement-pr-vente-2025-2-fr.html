Fonctionnement des rabais
Dans les années passées, nous offrions une quantité limitée de rabais de 12, 15 et 20%, avec le principe du premier arrivé premier servi. Cette année, nous avons décidé d’adopter une mode de fonctionnement plus équitable: 
 
  • Rabais de 20% les 60 premières minutes, de 9h00 à 10h00 le 13 septembre avec le code LASCLAY20

  • Rabais de 15% le reste de la journée du 13 septembre, jusqu’à 23h59, avec le code LASCLAY15

  • Rabais de 12% le dimanche 14 septembre, jusqu’à 23h59 avec le code LASCLAY12.
