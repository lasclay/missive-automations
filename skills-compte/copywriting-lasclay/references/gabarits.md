# Gabarits

Squelettes réutilisables. Ce sont des points de départ, pas des moules. Si le
gabarit rend le texte plus plat que la matière réelle, abandonne-le.

## Transparence longue (annonce difficile)

```
[Phrase directe ou inconfortable.]

Je veux prendre le temps d'expliquer pourquoi.

[Contexte historique.]

À ce moment-là, c'était la bonne décision parce que:
1. [...]
2. [...]
3. [...]

Mais avec le temps, une autre réalité est apparue.

[Contraintes concrètes.]

Le problème, ce n'était pas [fausse explication].
Le problème, c'était [vraie explication nuancée].

Donc on a décidé de [décision].

Ce que ça change:
- [...]

Ce que ça ne change pas:
- [...]

Je comprends que cette décision puisse décevoir certaines personnes.
Je préfère l'expliquer clairement plutôt que de faire semblant qu'elle est plus
simple qu'elle ne l'est.
```

## Post LinkedIn (pivot ou décision)

```
[Hook: phrase directe et un peu inconfortable, autonome.]

[2-3 lignes de contexte concret. Un chiffre réel si autorisé.]

À ce moment-là, c'était la bonne décision. Ça nous a permis de:
- [apprentissage 1]
- [apprentissage 2]

Mais une autre réalité est apparue.

[La vraie contrainte, nommée sans drame.]

Le problème, ce n'était pas [fausse explication].
C'était [vraie explication nuancée].

Ce qui change: [...]
Ce qui ne change pas: [l'asclépiade, la mission monarque, la conception, la
qualité.]

Je ne demande à personne d'être d'accord. Je veux juste que la décision soit
comprise.

[Vraie question à la communauté.]

[1 à 5 hashtags]
```

## Post Facebook organique (récit)

```
[Accroche-choc: une scène ou un chiffre, sans explication. Phrase nominale
possible.]

[On recule. Le contexte concret, la matière, l'atelier.]

[La tension réelle: le modèle qui plafonne, la basse saison qui brûle de
l'argent, la fatigue.]

À un moment, j'ai dû choisir.

[La décision.]

Ce que ça m'a coûté: [vrai, sobre.]

Ce qui ne change pas: la culture et la transformation de l'asclépiade restent au
Québec. C'est non négociable. Sans ça, Lasclay perd son sens.

[Chute sobre. Pas de slogan positif forcé.]
```

## Infolettre communautaire

```
Objet:
[Annonce claire, pas de mystère marketing]

Préheader:
[La tension en une ligne]

Bonjour,

Je voulais vous écrire directement parce qu'on a une décision importante à vous
expliquer.

[Annonce claire.]

Je sais que pour plusieurs d'entre vous, ce sujet compte beaucoup.
Il compte pour nous aussi.

[Histoire, contexte.]

[Explication.]

[Ce qui change.]

[Ce qui reste.]

Merci de nous lire, même quand le sujet est moins simple qu'un lancement de
produit.

Chaleureusement,
Gabriel
```

## Réponse à une critique

```
Je comprends votre réaction.

[Reconnaissance spécifique, pas générique.]

Ce qu'on ne veut pas faire, c'est prétendre que cette décision est anodine.

[Correction ou précision factuelle.]

La raison principale est [raison claire], pas [interprétation erronée].

Vous avez le droit de ne pas être d'accord.
On préfère quand même l'expliquer ouvertement plutôt que de laisser les gens
deviner.
```
